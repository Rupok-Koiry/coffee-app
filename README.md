# ☕ Coffee Ordering App

This is a **Coffee Ordering App** built with **Expo Router**, designed to deliver a seamless coffee shopping experience. The app includes features such as adding coffee items to a cart, secure payment via **Stripe**, order tracking, and an admin dashboard to manage orders and products.

---

## 🎯 Features

### User Features
- **🛒 Add to Cart**: Browse coffee options and add them to the cart.
- **💳 Payment Integration**: Pay securely through **Stripe**.
- **📦 Order Tracking**: Track the status of your order in real-time.
- **🔍 Product Search**: Search for specific coffee products using keywords.
- **🗂️ Category Filtering**: Filter products by categories for easier navigation.
- **💖 Wishlist**: Save your favorite products for future purchases.
- **🌟 Ratings & Reviews**: View product ratings and user reviews before making a purchase.

### Admin Features
- **📋 Manage Orders**: Approve, edit, or delete orders.
- **📦 Manage Products**: Add, update, or remove products from the inventory.
- **📊 Analytics Dashboard**: Monitor sales and user activities.

### UI Features
- **🎨 Modern UI**: A clean and responsive design for enhanced user experience.
- **✨ Thematic Design**: Theme implementation for a consistent and visually appealing layout.
- **🎥 Animations**: Smooth animations for empty lists and pop-ups.
- **📱 Responsive Design**: Optimized for both mobile and tablet devices.

---

## 🚀 Installation

1. Clone the repository to your local machine:

   ```bash
   git clone https://github.com/yourusername/coffee-ordering-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd coffee-ordering-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the app:

   ```bash
   npx expo start
   ```

## 🛠️ Technologies Used

- **Expo Router**: For navigation and routing.
- **React Native**: For building the app UI.
- **Stripe**: For secure payment processing.
- **Supabase**: For backend and edge function updates.
- **TypeScript**: For type-safe coding.
